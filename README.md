# Biomaterials Data Analysis in R

## Overview

This repository contains reproducible R workflows developed for the statistical analysis and visualization of biomaterial characterization data generated during my MSc Biotechnology research.

The analyses demonstrate data processing, statistical testing, publication-quality visualization, and automated report generation using R.

> **Note**
>
> The experimental datasets are **not included** because they form part of ongoing unpublished research. This repository is intended to demonstrate the computational workflow, statistical analyses, and coding practices.

---

## Analyses Included

### 1. Swelling Analysis

- Data preprocessing and cleaning
- Swelling percentage calculation
- Mean ± SEM summary statistics
- Publication-quality line plots with error bars
- Welch's t-tests at individual time points
- Two-way ANOVA
- Automated Excel report generation

---

### 2. Porosity Analysis

- Scaffold volume calculation
- Pore volume calculation
- Porosity percentage calculation
- Mean ± SEM summary statistics
- Publication-quality bar plots with individual data points
- Welch's t-test
- Automated statistical reporting
- Excel report generation

---

### 3. Rheological Characterization

- Frequency sweep analysis
- Storage modulus (G') visualization
- Loss modulus (G'') visualization
- Combined rheology plots
- Publication-quality figure generation

---

### 4. Drug Loading Efficiency Analysis

- Standard curve generation using linear regression
- Drug concentration estimation
- Drug loading efficiency calculation
- Mean ± SEM summary statistics
- Publication-quality bar plots with individual data points
- Welch's t-tests
- Two-way ANOVA
- Automated Excel report generation
